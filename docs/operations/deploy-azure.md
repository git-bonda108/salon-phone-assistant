# Deploy to Azure Switzerland North

Infrastructure as code ([`infra/main.bicep`](../../infra/main.bicep)), deployed by GitHub Actions with OpenID Connect: **no stored secret anywhere** ([0007](../decisions/0007-keyless-deployment.md)).

## What gets created (one resource group, Switzerland North)

| Resource | Purpose |
| --- | --- |
| Container App (1 replica) + environment | the backend: live tools, MCP, agents, webhooks, web app |
| Container Registry (Basic) | images, built remotely by `azd` (no Docker needed locally) |
| User-assigned managed identity | keyless access to everything below |
| Azure AI Services (Foundry) account + project `lina` | Azure OpenAI (`gpt-4.1-mini`, **Standard = regional**), Content Safety, AI Language. Local auth disabled |
| Key Vault (RBAC) | tool key, admin token, webhook secret (generated by the app on first start), calendar credentials |
| Log Analytics + Application Insights | logs, requests, agent spans |

Roles: the app identity gets *AcrPull*, *Key Vault Secrets Officer*, *Cognitive Services OpenAI User* and *Cognitive Services User*. The deploy identity only has *Contributor* and *Role Based Access Control Administrator* on this one resource group.

## One-time setup (about 5 minutes)

1. Open **Azure Cloud Shell** (Bash) at <https://shell.azure.com>, signed in as subscription owner.
2. Run:
   ```bash
   curl -sSL https://raw.githubusercontent.com/git-bonda108/salon-phone-assistant/main/infra/bootstrap.sh | bash
   ```
3. Copy the printed values to **GitHub → repository → Settings → Secrets and variables → Actions → Variables**: `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`, `AZURE_RESOURCE_GROUP`, `AZURE_LOCATION`, `AZURE_OWNER_OBJECT_ID`, `GRAPH_CLIENT_ID`. They are identifiers, not secrets. If `gh` is signed in inside Cloud Shell, the script sets them for you.
4. Run the **deploy** workflow (Actions → deploy → Run workflow), or push to `main`.

The workflow runs the tests, `azd provision` (Bicep), `azd deploy` (remote image build) and [`verify_deployment.py`](../../scripts/verify_deployment.py).

**Model quota:** new subscriptions sometimes have no regional quota for a model. If provisioning fails on the model deployment, request quota for `gpt-4.1-mini` *Standard* in Switzerland North (Foundry portal → Quotas). Global or DataZone deployments are not a fallback ([0004](../decisions/0004-switzerland-only-processing.md)).

## After the first deployment

1. **Connect Suisse Line:** in the Azure portal, open the Key Vault (`kv-lina-…`) → Secrets: copy `tool-api-key` into each live tool's `X-Api-Key` header and `webhook-secret` into the Suisse Line webhook. Base URL = the `SERVICE_API_URI` output.
2. **Full verification:**
   ```bash
   TOOL_API_KEY=… ADMIN_TOKEN=… python scripts/verify_deployment.py https://ca-lina-….azurecontainerapps.io
   ```
3. **Calendar:** see [Outlook](outlook-setup.md) or [Google](google-calendar-setup.md), then set the repository variables `CALENDAR_BACKEND` (and `GRAPH_CALENDARS`) and redeploy.

## Settings reference

| Variable (repo variable → app env) | Default | Meaning |
| --- | --- | --- |
| `CALENDAR_BACKEND` | `sqlite` | `sqlite` (demo) · `google` · `outlook` |
| `GRAPH_CALENDARS` | `{}` | stylist → `{"user": "me" or UPN, "calendar_id": …}` |
| `DEPLOY_JUDGE` | `false` | also deploy `gpt-5.1` (regional) for the call reviewer and the evaluation judge |

## Operating notes

* **State:** appointments live in the calendar. Waitlist, offers, call reviews and traces live in SQLite on the single replica, so a restart clears them. For a pilot, move the store to Azure Database for PostgreSQL in the same region.
* **Logs:** App Insights → *Transaction search* (requests, tool calls, agent spans), *Failures*.
* **Rotate a secret:** delete it in Key Vault and restart the revision; the app generates a new one. Then update Suisse Line.
* **Roll back:** Container App → Revisions → activate the previous revision.
* **Cost (demo scale):** Container App with 1 replica, Basic registry, Key Vault and Log Analytics run to a few CHF per day. Models, Content Safety and Language are billed per use.
