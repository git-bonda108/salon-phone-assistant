# 0007 · Keyless deployment: GitHub OIDC and managed identity

**Context.** API keys in CI variables or app settings leak.

**Decision.** GitHub Actions authenticates to Azure with OpenID Connect (federated credential, no client secret). The Container App uses a user-assigned managed identity for Azure OpenAI, Speech, Language, Content Safety, Key Vault and the registry, with local keys disabled where the service allows it. Our own secrets (tool key, admin token, webhook secret) are **generated by the app on first start** directly in Key Vault, so no secret is ever typed, pasted or committed. Third-party credentials (calendar) are added to Key Vault by the owner.

**Consequences.** One-time setup needs an Azure owner to run a bootstrap script in Cloud Shell. Infrastructure is declared in Bicep and deployed with `azd`, so the environment can be rebuilt from the repository.
